# Risk Ledger — OpenSMS Next

| ID | Risiko | Dampak | Kontrol / tindakan | Status |
|---|---|---|---|---|
| R-01 | `SEND_SMS` adalah permission sensitif; Google Play saat ini membatasi permission ini untuk default SMS/Assistant handler, role yang belum diimplementasikan OpenSMS. | APK dapat ditolak/dihapus dari Play atau distribusi publik tidak memenuhi kebijakan. | Tidak klaim kesiapan Play; distribusi internal/sideload tetap blocker policy owner sebelum rilis. | Blocker rilis publik |
| R-02 | Kelayakan foreground service untuk listener HTTP kontinu belum dibuktikan. `remoteMessaging` ditujukan untuk kesinambungan pesan antarperangkat; `dataSync` bukan jalan pintas uptime. | Service dihentikan OS, aplikasi melanggar aturan, atau klaim uptime salah. | MVP memakai bound session-only service tanpa FGS; berhenti saat app background. Review tipe service tetap wajib sebelum mengubah perilaku ini. | Diterima untuk MVP |
| R-03 | Target API 37 mengharuskan izin LAN runtime bagi socket lokal masuk/keluar. | API LAN gagal saat permission belum diberi/dicabut. | Kode meminta `ACCESS_LOCAL_NETWORK`, bind ke alamat IPv4 Wi-Fi aktif, dan memeriksa subnet privat allowlist. Grant/deny/revoke pada perangkat API 37 masih harus diuji. | Terbuka |
| R-04 | Ktor CIO telah diuji di AVD API 35, belum Android 14–17 fisik, khususnya LAN, perubahan network, dan idle cost. | Engine/server tidak cocok atau tidak stabil di perangkat produksi. | Pertahankan adapter; jalankan matriks fisik dan soak test, ganti adapter bila bukti gagal tanpa mengubah kontrak. | Terbuka |
| R-05 | Queue Room dan idempotency sudah berjalan, tetapi 202/radio callback belum diuji dengan radio nyata. | Request dianggap durable namun terjadi perilaku modem/OEM berbeda. | Commit transaction sebelum 202; gunakan fake sender/API integration tests; verifikasi end-to-end pada perangkat ber-SIM. | Terbuka |
| R-06 | Callback radio hilang setelah dispatch dapat membuat hasil tidak diketahui. | Retry otomatis berisiko mengirim SMS ganda. | Reconcile in-flight ke `UNKNOWN`; jangan auto-resend setelah invocation ambigu. | Persyaratan wajib |
| R-07 | SMS destination/body sensitif dapat bocor lewat log, DB, backup, atau export. | Paparan privasi dan data penerima. | AES-GCM field encryption, Keystore keys, backup off, no-body UI/log; tes erasure, retention, dan key loss tetap dibutuhkan. | Sebagian ditangani |
| R-08 | HTTP + Bearer pada LAN tidak memberi enkripsi transport; LAN bersama dapat menyadap token/body. | Penyalahgunaan token dan kebocoran SMS. | Batasi binding ke jaringan tepercaya; tidak expose WAN; TLS hanya melalui proxy/tunnel yang dirancang dan disetujui admin. | Terbuka |
| R-09 | Pemilihan SIM berubah/hilang atau OEM mengimplementasikan callback berbeda. | SMS terkirim lewat SIM salah atau status tidak akurat. | Pilih `subscriptionId` aktif eksplisit; no silent fallback; pengujian dual-SIM dan OEM fisik. | Terbuka |
| R-10 | Workspace saat ini bukan checkout Git dan tidak memuat sumber/lisensi upstream. | Audit perilaku dan kepatuhan atribusi tidak lengkap. | Hindari menyalin kode; audit file license/upstream lengkap sebelum memakai source. | Terbuka |
| R-11 | SDK API 37 ada tetapi hanya AVD Android 15/API 35 tersedia dan tidak punya radio SMS. | Tidak ada bukti runtime/API 37, permission LAN, atau SMS hardware. | Laporkan validasi fisik sebagai `NOT RUN`; siapkan matriks perangkat sebelum acceptance release. | Blocker validasi |
| R-12 | Listener menggunakan HTTP tanpa TLS; Bearer key dapat disadap bila jaringan bersama dikompromi. | Penyalahgunaan kunci dan pesan. | Bind hanya ke Wi-Fi + subnet privat allowlist; batasi jaringan ke LAN tepercaya, gunakan tunnel/TLS terkelola untuk akses luar LAN. | Terbuka |
| R-13 | Keystore field key hilang/invalid dapat membuat ciphertext lama tak terbaca. | Riwayat tidak dapat dibuka; data SMS hilang. | Tidak auto-resend; tandai prep gagal, backup dimatikan; belum ada pemulihan/admin UI. | Terbuka |
